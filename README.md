# Visitor Register

A digital version of the paper register used to sign in before using a computer at a library.

## Why this project
In my hometown, you must fill in a paper register before using a library computer. This project replaces that paper with a digital form.

## What the form collects
- Name and surname
- Date and time (set automatically when the form is submitted)
- Phone number
- Reason for visit
- Drawn signature

Every field is compulsory, just like on the paper register.

## Built with
- C#
- ASP.NET Core MVC

## Status
In progress. The Visitor model is done and the controller is next. Visitors are kept in memory for now, with no database yet.

## Planned
